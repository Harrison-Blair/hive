second is Codex in the worktree. The third is Claude Code in a scratch
repository below `.hive/tmp/` with no hive files. The scratch session gets the
T14 worker prompt with the worktree as the home.

frontmatter description of its skill.

  sleep 3
  herdr pane read w54:p2 --lines 16
  herdr pane send-keys w54:p2 ctrl+c
