# V2 — CLI refusal from the task worktree

Built the task binary with `go build -o ./hive .`. I made a marked scratch home with a live coordinator fixture and a temporary XDG config directory. From this worktree, I ran:

```sh
HIVE_HOME=<scratch-home> XDG_CONFIG_HOME=<scratch-config> ./hive chat send hello
```

Result: exit status 1. Output:

```text
hive: chat send is for the user only: only the user can send chat; rule 2 (working directory is below projects/)
```

The scratch home had no `.hive/state/chat/*.jsonl` file after the command.
