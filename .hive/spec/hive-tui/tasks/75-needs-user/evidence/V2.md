# V2 — Temporary-home command check

`go test ./cmd/task/edit -run '^TestNeedsUserEditFlow$' -count=1` passed.

The test uses temporary `HIVE_HOME` and `XDG_CONFIG_HOME` directories. It sets `needs_user` on a verified task, then checks text and JSON show output and text and JSON list output. It clears the field and checks that show and list omit it. It confirms that a worker cannot edit the field. It also checks set and clear on a completed task, and rejects text with more than 200 characters or a line break.

The test creates no herdr workspace. Go removes its temporary directories after the test.
