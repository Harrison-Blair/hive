## Rules used

- If a record has `parent` or `replaces`, group its identity by role, project, and task. Otherwise, group it by name.
- A record named in another record's `replaces` field is old. For each remaining identity, keep the newest `status_changed_at`, then the newest record time. Use the key to break a final tie.
- By default, show only the current generation. Show a stopped worker or verifier as a dim ghost only when its task is active. A task is active when its status is not `done` and it is not landed. A task is landed when its delivery has a non-empty commit and `pushed` is true.
- Keep history off at startup. With history on, show every record and dim old or stopped records.
- A stopped worker of a landed task stays hidden with history off. With history on, show it as a dim ghost with `✓` and a label such as `51 landed · e72190f`.

Manager decision: R1 controls default visibility. The board supplies the ghost's dim style, mark, and label. The board example does not make a landed task visible with history off.
