# V2 — Live screens and board comparison

## Live check

I built the task binary with `go build -o .hive/tmp/selection-marker-check/hive .`. I ran it in a scratch home with a temporary `XDG_CONFIG_HOME`. I removed `HERDR_ENV`, `HERDR_PANE_ID`, `HERDR_WORKSPACE_ID`, and `HERDR_SOCKET_PATH` from its environment.

I used pane `wTN:p3` in tab `wTN:t3`. The pane size was 207 × 57. I started process `3647179` and stopped it before I closed tab `wTN:t3`. The scratch supervisor claim used the live shell pid only to show fresh scratch status. I did not start `hive supervise` or a coordinator. The TUI showed `not in herdr: no coordinator or supervisor started`.

I moved each selection once. I changed the Chat noise level, then opened its composer and typed `selection marker draft`. I did not send the draft. I selected the graph node on Agents, moved the selected goal, queue task, task row, friction issue, Health check, and Logs event. I also opened the selected Logs event details.

I captured ANSI output for all eight screens. The audit found a honey-bold marker on each selected item. It found no default foreground code `38;2;232;228;218` and no background SGR. Logs has two selected items: the active level filter and the event row. The audit checked both.

The screenshots below use a 9 px font to fit the 207 × 57 pane in the required 1220 × 780 image size. The data differs from the design boards because the scratch home uses fixture records. The board PNGs remain under `/home/penguin/source/hive/.hive/tmp/102-selection-marker-boards/` and are not in the commit.
