# V1 — Test first

The worktree started at `ef2dde2e`, the same commit as `origin/dev`. The new model test failed before the screen change.

```text
go test ./internal/tui -run '^TestFrictionScreenShowsSelectedDetailsInRightPanel$' -count=1
```

Result on the base code: failed because the details were below the list. At 120 x 40, the list header began at column 32 and the entry title appeared at columns 47 and 32. The test expected the details to appear to the right of the list and beyond the frame midpoint.

After the change, the new test passed at both required sizes:

```text
go test ./internal/tui -run '^(TestFrictionScreenShowsSelectedDetailsInRightPanel|TestFrictionScreenLoadsEntriesAndOpensSelectedEntry|TestFramesMatchTerminalSizesOnEveryScreen)$' -count=1
ok   github.com/Harrison-Blair/hive/internal/tui
```

The test loads fixture data through the model, sends a window-size message, and checks the rendered `View`. It also checks that the `decision` column remains visible.
