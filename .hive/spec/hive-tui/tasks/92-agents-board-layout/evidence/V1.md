## Nudge-edge test-first run

The graph load reads inbox data in its background command. It draws one dashed edge from the supervisor to a coordinator or manager when that inbox has an unread record with `NudgedAt` set. A read record or an empty `NudgedAt` draws no edge. Workers and verifiers get no nudge edge. The legend stays visible in each case.

Before I added inbox loading and edge rendering, this command failed as expected:

```sh
go test ./internal/tui -run '^TestAgentsNudgeEdges' -count=1
```

The unread nudged manager and coordinator cases found zero edges, where each expected one. The read-record and no-`NudgedAt` cases expected no edge. The worker and verifier cases expected no edge.

After the change, the same command passed:

```text
ok   github.com/Harrison-Blair/hive/internal/tui
```
