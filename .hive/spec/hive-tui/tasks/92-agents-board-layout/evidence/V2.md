## Board comparison

I compared each golden frame line with the matching region of `Main.dc.html` before I saved it. I then checked the live captures against the same regions: header, explorer, tabs and legend, graph, detail strip, and key bar.

- The header uses `supervisor ●` and `needs you`. The pod titles use `≡`. Graph harness labels use `cc`. The detail strip has a border. The key bar says `h hide stopped`.
- The graph draws the delegation bus and stems, the dashed nudge edge, and node boxes. It has no text list of graph edges. The stopped verifier appears as a ghost because task 92 is open.
- The selected live node is `t92-worker-2`, while the board uses fixture data. The names, task values, models, pane IDs, ages, counts, and time therefore differ.
- The old manager records have no explicit parent. G4 marks their manager edges as `inferred`.
- T3 hides stopped generations by default. The older `t92-worker-1` generation is hidden; the tree and table still show the replacement relation where the data supports it.
- The 120 x 40 graph cannot show every project pod at once. It follows the selected node and clips other columns at the panel edge. Its lines remain within 120 cells. The graph-selection test checks movement and scrolling.
- The table keeps the full record fields. It uses ellipses for long values at 120 x 40. The text capture strips terminal colors, so it does not show honey text or the absence of background fill.
- The footer shows `not in herdr: no coordinator or supervisor started` and the Chat guard error for a worktree below `projects/`. These messages follow the scratch-home check rules. I did not open the Chat input or press Enter.

The supervisor row uses the live lifecycle record for status and age, and the matching claim for its PID. The old load path passed only a boolean to the generic status mapper. The supervisor record had no `agent_status`, so the mapper returned `unknown`. The old graph also used no claim PID fallback and used only `status_changed_at` for age. The live capture now shows the supervisor PID and age.
