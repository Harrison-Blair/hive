# V2 — live TUI in Herdr

Herdr was 0.9.5 with protocol 22. I built the task binary and ran it in a new,
background Herdr workspace. The temporary home had two valid live agent records
and a temporary `XDG_CONFIG_HOME`.

```sh
go build -o .hive/tmp/<live-check>/hive .
herdr workspace create --cwd "$PWD" --label 79-tui-shell-live --no-focus
herdr pane split --pane <root-pane> --direction right --ratio 0.5 --no-focus
herdr pane resize --direction left --amount 0.05 --pane <root-pane>
herdr pane run <root-pane> 'env HIVE_HOME=<temp-home> XDG_CONFIG_HOME=<temp-config> <task-binary>'
```

The first resize made the pane 93 columns wide. I read the visible pane after
each key. Keys `1` to `7` showed the matching selected screen and its `next
wave` placeholder. Key `8` showed Logs. Key `q` left Logs selected and the TUI
running. A further resize made the pane 91 columns wide; the header, compact
sidebar, panel, and footer remained visible.

The first `ctrl+c` showed `press ctrl+c again to quit`. After four seconds the
notice was gone and the TUI remained open. The next `ctrl+c` showed the notice
again. A second `ctrl+c` exited to the shell prompt.

The cleanup trap closed the temporary workspace and removed the temporary home,
config, and binary. A follow-up `herdr workspace list` showed no workspace with
the live-check label, and `find .hive/tmp -maxdepth 1 -name '79-tui-live.*'`
returned no paths.
