# V2: Herdr live check

## Setup and result

- Built the binary with `go build -o /tmp/hive-chat-noise-v2.pSSz9E/bin/hive .`.
- Set `HIVE_HOME` to `/tmp/hive-chat-noise-v2.pSSz9E/home` and `XDG_CONFIG_HOME` to `/tmp/hive-chat-noise-v2.pSSz9E/config`.
- Copied `.hive/README.md` into the temporary home. Added coordinator and supervisor fixtures and inbox records for all seven kinds.
- Ran the binary in Herdr workspace `wQ6`, pane `wQ6:p1`. The pane layout was 207 x 57 cells.
- Read the screen with `herdr pane read wQ6:p1 --source visible --lines 57` at each noise level.
- Did not open Chat input. Sent only `n` to change the noise level.
- Closed workspace `wQ6`. Removed the temporary home, config, and binary.

The default view showed `landings and decisions`: one `message`, one `completed`, and one `verified` record. `decisions only` showed the `message` record. `all` showed all seven inbox kinds.
