# V1: Chat noise levels

## Inbox kinds

- `all` shows `message`, `completed`, `verified`, `blocked`, `exited`, `quiet`, and `unresolved`.
- `decisions only` shows `message`, `blocked`, and `unresolved`.
- `landings and decisions` (default) shows the kinds of `decisions only`, plus `completed`, `verified`, and `quiet`.

## Test-first result

After merging `origin/dev` and before the repair, the changed default-level subtests failed because the current code showed only `message`, `completed`, and `verified`:

```text
go test ./internal/tui -run '^TestChatNoiseLevelsFilterInboxKinds/landings_and_decisions$' -count=1

visible inbox kinds = [completed message verified]; want [blocked completed message quiet unresolved verified]
```

The changed decisions-only subtest also failed because the current code showed only `message`:

```text
go test ./internal/tui -run '^TestChatNoiseLevelsFilterInboxKinds/decisions_only$' -count=1

visible inbox kinds = [message]; want [blocked message unresolved]
```

The changed `TestChatNoiseAndEventFoldingDoNotMarkRecordsRead` test failed against the pre-repair code. That code showed one event instead of two at the default level:

```text
go test ./internal/tui -run '^TestChatNoiseAndEventFoldingDoNotMarkRecordsRead$' -count=1

view does not contain "2 hive events"
```

The changed tests passed after the repair. They check literal kind sets and literal view text at each level, using model `Update` and `View` calls:

```text
go test ./internal/tui -run '^(TestChatNoiseAndEventFoldingDoNotMarkRecordsRead|TestChatNoiseLevelsFilterInboxKinds)$' -count=1

ok   github.com/Harrison-Blair/hive/internal/tui
```
