- Built the task binary with `go build -o /tmp/hive-100-no-backgrounds-01a15a00-3c3f-747c-bdab-2785c6e4cdeb/hive .`.
- Ran it in task-owned herdr tab `wQ5:t2` with a scratch `HIVE_HOME` and `XDG_CONFIG_HOME`. Herdr startup was disabled inside the TUI process to prevent coordinator or supervisor startup.
- Captured all eight selected screens with `herdr pane read --format ansi --lines 60`.
- Result: all eight captures had no background or reverse-video SGR codes. Each capture retained the selected sidebar's honey foreground and selection marker.
- Closed the task-owned tab after the TUI exited. The Chat input was not opened.
