# V2: Live Logs frame check

I built the task binary with `go build -o /tmp/hive-120-logs-filter-fit .`. The command exited with status 0.

I started the binary in task tab `wV5:t2`, pane `wV5:p2`. The process used a scratch `HIVE_HOME` and a temporary `XDG_CONFIG_HOME`. The command cleared `HERDR_ENV`, `HERDR_PANE_ID`, `HERDR_WORKSPACE_ID`, and `HERDR_SOCKET_PATH`.

I opened Logs in two tmux panes. I set a long text filter in each pane.

| Session | Pane size | Filter | Result |
| --- | --- | --- | --- |
| `logs120` | 120 x 40 | `filter filter` | The frame used 40 rows and 120 columns. The Logs panel bottom border showed. |
| `logs200` | 200 x 57 | Ten `filter` words | The frame used 57 rows and 200 columns. The Logs panel bottom border showed. |

`tmux display-message` reported `120x40 120x40` for `logs120` and `200x57 200x57` for `logs200`. The two screen captures are `120x40.png` and `200x57.png` in this evidence folder.
