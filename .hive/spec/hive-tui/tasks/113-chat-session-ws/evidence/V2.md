# V2 — Rule review

`Send` and `ValidateCaller` call `checkAgentCaller` before `checkCallerContext`, so rule 1 remains first. `checkCallerContext` checks the working directory against `projects/` before pane lookup and rule 3, so rule 2 remains active.

After pane lookup, the code uses `identity.ResolveHeld(locked, "coordinator", "")`. This resolves a live coordinator through its held claim. The function returns early only when the pane workspace matches that coordinator's workspace. Otherwise, it scans live manager, worker, and verifier records and refuses a match. If no live coordinator resolves, the scan still runs. The added tests cover each path, including rule 1 and rule 2 in the coordinator workspace.
