## Run

I built the task branch binary. I used a temporary `HIVE_HOME` with a home marker.

```sh
hive task list --project x
hive logs --json
hive logs --request r-58037852 --json
```

`task list` printed `no tasks` and exited 0. The unfiltered log output contained its start and end events. Both events had request ID `r-58037852`.

The filtered output had only these two events:

```json
{"command":"task list","component":"cli","level":"DEBUG","msg":"command start","request_id":"r-58037852","time":"2026-10-20T03:09:28.558000868-04:00"}
{"command":"task list","component":"cli","duration_ms":0,"level":"DEBUG","msg":"command end","outcome":"ok","request_id":"r-58037852","time":"2026-10-20T03:09:28.558060459-04:00"}
```

The request filter returned two events. Both carried the selected request ID. The end event had `duration_ms` and outcome `ok`.
