Built the task binary, made a temporary home, started a copied `sleep` executable with an older mtime, and added a live supervisor claim plus a delivered task at `projects/demo/worktrees/1-landed`.

`HIVE_HOME=<temp-home> PATH=<temp-bin>:$PATH <temp-bin>/hive doctor` printed:

```text
warn supervisor binary: supervisor <old executable> modified 2026-10-20T04:54:57.45310559Z; hive <task binary> modified 2026-10-20T06:54:57.449676997Z; supervisor binary is older
warn stale worktrees: demo/1-landed
```

`hive doctor --json` returned `supervisor binary=warn` and `stale worktrees=warn`. JSON details included both executable times and `demo/1-landed`. The temporary home, process, and binaries were removed by the check cleanup.
