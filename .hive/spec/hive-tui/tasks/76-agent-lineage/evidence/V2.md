# V2: Live lineage check in Herdr

Herdr reported version 0.9.5 and protocol 22. I used a `hive` binary built from this task branch, with a temporary `HIVE_HOME` and a temporary `XDG_CONFIG_HOME`.

1. Registered project `hive` in the temporary home.
2. Created workspace `wJX` and registered a fake manager named `manager-hive`. Its Hive record key was `manager-hive-g1`.
3. Created task `1-lineage-live`.
4. Spawned a Pi worker with `--agent manager-hive` in workspace `wJY`. Hive named the worker `t1-worker-1`.
5. Stopped the first worker. Herdr closed pane `wJY:p1` and workspace `wJY`.
6. Spawned the same task again in workspace `wJZ`. Hive named the worker `t1-worker-2`.
7. Ran `hive agent show t1-worker-2`. It printed:

```text
parent: manager-hive-g1
replaces: t1-worker-1
```

8. Stopped the second worker. Herdr closed pane `wJZ:p1` and workspace `wJZ`. I closed manager workspace `wJX` and removed the temporary home, config, and binary.

Result: pass. The output showed the manager as parent and the first worker as the replaced record. The live-check script reported `V2 cleanup verified`.
