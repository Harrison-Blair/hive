# V2 Rectangles

Proves AC1, AC2, AC3. A rectangle is `rect{row, col, width, height}` in the
board grid (`.hive/spec/tui-v2/design/<Board>.grid`). `checkGolden` compares
each cell (character, token, bold) of the rectangle with the component
output. The board script draws each component with `box(t, x, y, w, h, …)`,
so x = col, y = row.
