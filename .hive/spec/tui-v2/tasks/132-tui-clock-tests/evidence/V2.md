## Change

Each test now sets the model clock to `time.Date(2026, 10, 20, 8, 0, 0, 0, time.Local)` after `chatModel`. The header formats `m.now()` in its own zone, so the clock text is `08:00` in each zone. The expected text stays a literal `08:00`. The fix needs no shared helper, so `internal/tui/tui_test.go` has no change.
