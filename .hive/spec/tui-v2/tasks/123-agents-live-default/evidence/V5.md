## Card border check, both sizes

A scratch script read the colour of each cell from the ANSI captures. For each
card it checked each cell of the border against the expected token: `accent`
for a selected (heavy) card, `working` for a card whose sub line says
`working`, and `border` for each other card. It also checked that the rail
cell to the left of each card joint (`├`, `╰`, `│`) is `border`. Output:
`captures/V5-cardcheck.txt`: **71 cards, 0 fail**. When the script ran on a copy of a
capture with the working border recoloured to `border`, it reported 5 of 9
cards as fail, so it does detect the fault.
