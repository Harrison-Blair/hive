## Decisions of the worker

- Registry: `frameScreen.panels` maps a view name to `screenPanels` (a list
  function and a details function). The text is the same as in task
  `36-screen-work-queue`, so the two branches add the same lines.
- No component change. `component.List` draws the unselected marker in fg, and
  the Components board needs that. The screen boards draw it as an accent bold
  space, so the Goals screen draws its rows in a `component.Panel`.
- The `no design for this wave` notice moved from the content to the footer,
  so that it shows at each width.
- Wave status: `✓ done` in `done`. Another status shows `○` and the word in
  `dim`. Goal status: `active` in `working`, `planned` in `info`, `done` in
  `done`, another word in fg.
- `manager` shows `manager-` and the project ID, the name that hive gives the
  manager of a project.
- A task of a wave shows `merge` and the first 8 characters of the commit when
  it landed. Otherwise it shows its glyph and its status word.
