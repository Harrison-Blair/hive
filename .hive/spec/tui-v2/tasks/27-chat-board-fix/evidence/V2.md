## Method

A scratch Go program (source below) reads the `dev` grid (`git show dev:PATH`)
and the task grid with `cellgrid.ReadGrid`, and calls `cellgrid.Compare` with
no masks. It lists the changed cells for each row. Then it checks each run of
the report (Chat: section 1, CompactChat: section 3) cell by cell: the rune, the
token, and bold=0. It also checks that the cells from the end of each report row
to the wrap width (94 or 76) are spaces in fg, not bold. The table origin is
grid row 15 col 23 for Chat (panel col 23 = `X`), and grid row 10 col 2 for CompactChat.

Self-check: with the `dev` grid in place of the task grid, the same report
check gives 313 mismatches (Chat) and 150 mismatches (CompactChat). The check
can therefore fail.

## Comparison program

It was at `.hive/tmp/gridcmp/main.go` and is now removed. Run as
`go run ./.hive/tmp/gridcmp BOARD ROW0 COL0 RUNSFILE WIDTH [dev]`. RUNSFILE
holds the report runs as `ROW C0 C1 TOKEN "TEXT"`, taken from the report with a short script.

```go
package main

import (
	"fmt"
	"os"
	"os/exec"
	"strings"

	"github.com/Harrison-Blair/hive/internal/lib/cellgrid"
)

func load(rev, path string) cellgrid.Grid {
	var data []byte
	var err error
	if rev == "" {
		data, err = os.ReadFile(path)
	} else {
		data, err = exec.Command("git", "show", rev+":"+path).Output()
	}
	if err != nil {
		panic(err)
	}
	g, err := cellgrid.ReadGrid(strings.NewReader(string(data)))
	if err != nil {
		panic(err)
	}
	return g
}

func main() {
	name, row0, col0 := os.Args[1], 0, 0
	fmt.Sscan(os.Args[2], &row0)
	fmt.Sscan(os.Args[3], &col0)
	path := ".hive/spec/tui-v2/design/" + name + ".grid"
	want, got := load("dev", path), load("", path)
	diffs, err := cellgrid.Compare(want, got, nil)
	if err != nil {
		panic(err)
	}
	rows := map[int][]int{}
	for _, d := range diffs {
		rows[d.Row] = append(rows[d.Row], d.Col)
	}
	fmt.Printf("%s: %d changed cells\n", name, len(diffs))
	for r := 0; r < want.Height; r++ {
		if cs, ok := rows[r]; ok {
			fmt.Printf("  row %d: %d cells, cols %d-%d\n", r, len(cs), cs[0], cs[len(cs)-1])
		}
	}
	// Report check: the report lines come on stdin as "ROW C0 C1 TOKEN TEXT".
	var width int
	fmt.Sscan(os.Args[5], &width)
	if len(os.Args) > 6 {
		got = want // self-check: the dev grid must fail the report
	}
	data, _ := os.ReadFile(os.Args[4])
	last := map[int]int{}
	bad := 0
	check := func(r, c int, ch rune, tok string) {
		cell := got.At(row0+r, col0+c)
		if cell.Rune != ch || cell.Token.String() != tok || cell.Bold {
			bad++
			fmt.Printf("  MISMATCH row %d col %d: got %q %s bold=%v, want %q %s\n", row0+r, col0+c, cell.Rune, cell.Token, cell.Bold, ch, tok)
		}
	}
	for _, ln := range strings.Split(strings.TrimSpace(string(data)), "\n") {
		var r, c0, c1 int
		var tok string
		fmt.Sscanf(ln, "%d %d %d %s", &r, &c0, &c1, &tok)
		q := strings.Index(ln, "\"")
		text := []rune(ln[q+1 : len(ln)-1])
		for i, ch := range text {
			check(r, c0+i, ch, tok)
		}
		last[r] = c1
	}
	for r, c1 := range last {
		for c := c1 + 1; c < width; c++ {
			check(r, c, ' ', "fg")
		}
	}
	fmt.Printf("  row 17 text: %q\n", rowText(got, 17))
	fmt.Printf("  row 18 text: %q\n", rowText(got, 18))
	fmt.Printf("  report cells checked, mismatches: %d\n", bad)
}

func rowText(g cellgrid.Grid, r int) string {
	var b strings.Builder
	for c := 0; c < g.Width; c++ {
		b.WriteRune(g.At(r, c).Rune)
	}
	return strings.TrimRight(b.String(), " ")
}
```
