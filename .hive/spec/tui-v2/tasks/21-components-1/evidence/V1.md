The new tests are in `internal/tui/component/*_test.go`. Each golden test
converts the output with `cellgrid.Convert` and compares it cell by cell with
`cellgrid.Compare`, with no mask. lipgloss renders each colour as a 24-bit SGR,
which is the TrueColor profile.

## Red run

The base is `dev` at 0fe6f78e in a scratch worktree. The red run copies the new
test files and one file of empty-body stubs into
`internal/tui/component/` of that worktree, uncommitted. The stubs give each new
symbol, so the tests compile and fail on an assertion.
