numbers are of the fixed board of task 22-components-board-fix.

Decisions on the samples:

- The board draws fixed scroll thumbs, so the Viewport tests pass the thumb
  cells of the board: `ScrollMark{Start: 1, Size: 2}` for the vertical mark
  and `ScrollMark{Start: 0, Size: 42}` for the horizontal mark. `Thumb()`
  computes a thumb for live use. `TestThumb` checks it with hand values. The
  manager approved this.
- The KeyHints sheet sample is 72 cells wide, the width of its text. The
  screen boards pad the hints in dim to the full width, and `KeyHints.View`
  does so too. The Main and CompactAgents rects check the padding. The manager
  approved this.

## Run

The command prints each rectangle with one row above and below it, and two
cells on each side of it, from the golden grid.

```sh
python3 - <<'PY'
rects = [("Components", 7, 0, 120, 1), ("CompactAgents", 0, 0, 80, 1),
         ("Components", 10, 0, 120, 2), ("Work", 1, 0, 120, 2), ("CompactFriction", 1, 0, 80, 2),
         ("Components", 14, 0, 120, 1), ("Work", 3, 0, 120, 1), ("CompactHealth", 3, 0, 80, 1),
         ("Components", 17, 0, 40, 5), ("Components", 17, 44, 40, 5),
         ("Components", 24, 0, 60, 7), ("Components", 24, 64, 56, 7),
         ("Components", 64, 0, 72, 1), ("Main", 39, 0, 120, 1), ("CompactAgents", 23, 0, 80, 1)]
for board, r, c, w, h in rects:
    lines = open(f".hive/spec/tui-v2/design/{board}.grid", encoding="utf-8").read().split("\n")
    text = [l[2:] for l in lines[1:] if l.startswith("t|")]
    print(f"== {board} row {r} col {c} {w}x{h}")
    for row in range(max(r - 1, 0), min(r + h + 1, len(text))):
        mark = ">" if r <= row < r + h else " "
        left, inside, right = text[row][max(c - 2, 0):c], text[row][c:c + w], text[row][c + w:c + w + 2]
        print(f"{row:2} {mark} {left!r:6} [{inside}] {right!r}")
PY
echo "exit $?"
```
