  (the merge of `dev` with the grids of task `42-wave6-board-redraw`).
- Pane: scratch tab `t34-live` (pane `w92:p2`, 57 rows) in the worker
  workspace `w92`. The tab has `HIVE_HOME` set to a scratch home under
  `.hive/tmp/t34/home` and `COLORTERM=truecolor`. The real home did not
  change. Demo mode starts no agent.
- Command: `hive --demo WORKTREE/.hive/spec/tui-v2/design/FIXTURE.fixture.json --size WxH`,
  with `Chat` at 120x40 and `CompactChat` at 80x24.
- Keys: `herdr pane send-keys w92:p2 KEY`. Herdr 0.9.5 has no key name for
  page up or page down, so `pgup` and `pgdn` were sent as the terminal
  sequences `ESC [5~` and `ESC [6~` with `herdr pane send-text`.

  after two reads 500 ms apart were equal. `herdr pane get` gave the scroll
  offset 0 for each capture. The CLI read has no `truncated` field; each
  capture has all of the board rows.
- Compare: a scratch program (`.hive/tmp/t34/livecmp`, not committed) crops the
  top-left W×H cells, converts them with `internal/lib/cellgrid`, and compares
  them with the board grid under the live rule of the manager decision: in a
  space cell, it does not compare the token or the bold flag.
- Screen PNGs and ANSI captures: `screens/` in this folder. A scratch script
  changed the SGR codes to an HTML `<pre>`, then
  `firefox --headless --no-remote --profile SCRATCH --window-size=1220,780 --screenshot OUT.png`.
- Board PNGs (not committed): `/home/penguin/source/hive/.hive/tmp/t34/boards/Chat.png`
  and `CompactChat.png`.
- After the check, the tab `t34-live` was closed. `herdr tab list --workspace w92`
  shows only `t34-worker-1`.
