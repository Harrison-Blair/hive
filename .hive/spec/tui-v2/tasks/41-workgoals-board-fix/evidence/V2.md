## Method

A scratch Go program (`.hive/tmp/v2cmp/main.go`, source below) reads the `dev`
grid (`git show dev:PATH`) and the task grid with `cellgrid.ReadGrid`, and
calls `cellgrid.Compare` with no masks. It prints each changed cell.

```go
package main

import (
	"fmt"
	"os"

	"github.com/Harrison-Blair/hive/internal/lib/cellgrid"
)

func read(p string) cellgrid.Grid {
	f, err := os.Open(p)
	if err != nil {
		panic(err)
	}
	defer f.Close()
	g, err := cellgrid.ReadGrid(f)
	if err != nil {
		panic(err)
	}
	return g
}

func main() {
	d, err := cellgrid.Compare(read(os.Args[1]), read(os.Args[2]), nil)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%d changed cells\n", len(d))
	fmt.Print(cellgrid.FormatDiffs(d))
}
```
