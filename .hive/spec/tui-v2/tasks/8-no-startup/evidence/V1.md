# V1 Tests

Proves: AC1.

New tests:

- `cmd/root_test.go` `TestBareHiveNoStartupMakesNoTabCalls` (subtests `flag` and `variable`): bare `hive` against a fake herdr server makes no `tab.create`, `tab.rename`, or `pane.send_input` call.
- `cmd/root_test.go` `TestBareHiveOtherNoStartupValueRunsStartup`: `HIVE_NO_STARTUP=true` has no effect; startup renames the tab.
- `internal/tui/startup_test.go` `TestStartupNoStartupSkipsEachStepAndLogsReason`: no herdr request, no notice, and a `skipped` log event with `reason` `no-startup` for each step.
