## Finding: a pane resize after start does not reach the program in a tab without focus

In an earlier try, a pane was split or closed while the demo ran. The pane rect from `herdr pane layout` changed (for example from 207×57 to 104×57), but the demo kept its first layout. Normal mode (`HIVE_NO_STARTUP=1`) did the same.

`stty size` showed the cause. In a pane of the tab that was made with `--no-focus`, `stty size` printed `55 100` after each split, close, and zoom, while the rect from `herdr pane layout` changed. herdr did not change the pty size of these panes, so the program got no resize signal. This is herdr behavior in a tab without focus. It is not a hive or demo defect. The check above starts each demo in a pane that already has its size. At the model, `TestDemoSizeShowsTooSmallInASmallerPane` sends a resize from 100×30 to 120×40 and sees the notice change to the TUI, so the demo applies each resize message that it gets.
