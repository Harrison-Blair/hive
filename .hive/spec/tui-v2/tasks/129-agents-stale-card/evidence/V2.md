# V2 Live check

## Setup

- Scratch home: `.hive/tmp/v2home` in the worktree, with `.hive/README.md`.
- `.hive/state/agents/`: the 20 fixtures of `internal/tui/testdata/agents-stale/`
  (`coordinator-g1..g8`, `manager-qmeter-g1..g4`, `manager-stenographer-g1..g8`).
  One more record, `worker-qmeter-g1`: a copy of `manager-qmeter-g1` with role
  `worker`, name `worker-qmeter`, and task `07-old`. It is stale, with no parent,
  no replaces, and no successor. The real home has no stale worker, so this record
  gives the case "a stale record with no live successor" (a manager card never
  hides with `h`, see V1).
- `.hive/state/projects/`: `qmeter` and `stenographer`.
- `.hive/state/claims/supervisor.json`: a claim on a scratch `sleep 3600` process
  with its start time, so the supervisor is fresh. No supervisor process ran.
- Binary: `go build -o .hive/tmp/hive129 .` on the task branch.
- Command: `HIVE_HOME=<scratch home> HIVE_NO_STARTUP=1 COLORTERM=truecolor .hive/tmp/hive129`, then `1` (Agents), then `h`, then `h`.

## Size

The herdr client of this session is 89 columns wide. A herdr pane cannot be
120×40 here: `stty size` in a new tab gave `61 89`. So the check ran two ways:

1. In the worker's own herdr tab `t129-v2` (pane `wWB:p3`, 89×61). Read with
   `herdr pane read wWB:p3 --source visible --format text`.
2. At exactly 120×40 in a private detached tmux server
   (`tmux -L t129v2 new-session -d -x 120 -y 40`). Read with
   `tmux capture-pane -p`.

Each capture is a plain-text file in `V2/`.
