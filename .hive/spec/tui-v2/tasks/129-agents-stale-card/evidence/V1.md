## Each rule and the test that breaks without it

| Rule | Test that fails without the rule |
| --- | --- |
| The name identity and the lineage identity of one record join | TestCurrentAgentKeysGiveOneRecordForEachName and the view tests |
| A live record is current before a newer stale record | TestCurrentAgentKeysPreferTheLiveRecord (seen to fail with the live check off) |
| Of two records with one name, the higher generation is newer | TestAgentsSupervisorRowUsesLifecycleClaimPIDAndStartAge (existing). With the joined identities, the old board record `supervisor` (generation 0, a later `status_changed_at`) took the place of the live `supervisor-g16` |
| `h` hides a stale card as it hides a stopped card | TestAgentsHHidesAStaleWorkerWithNoSuccessor |

## Cause

`agentIdentity` gave a record with no `parent` and no `replaces` the identity
`name`, and each other record the identity `lineage`. The old records of one
name and the newest record of that name were in two groups. `currentAgentKeys`
marked one record of each group as current. The fix gives each record its name
identity, and also its lineage identity when it has a `parent` or `replaces`,
and joins the identities of each record (union-find). General agents keep one
identity for each key.

## Decision on h and manager cards (manager-hive, 2026-10-23)

`h` hides a stale card with the same rule as a stopped card, for each card kind
that `h` hides now: workers, verifiers, and general agents. The count in
`h hides N stopped` and `h shows N stopped` includes it. Manager cards keep the
current design: `h` does not hide a manager card. So the `manager-stenographer`
card (current record g8, exited) stays in its pod after `h`. It now shows
`○ manager-stenograp… / claude · stopped · …` from g8, not `claude · unknown`
from g6. No other change to `h`. Health › Agents `h` is not changed.
