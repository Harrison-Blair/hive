Binary: task branch at `6c466dc6`, built with `go build -o /tmp/t135v4/bin/hive .`.

## Scratch setup

- Home: `/tmp/t135v4/home` with a home marker. `HIVE_HOME=/tmp/t135v4/home`, `HIVE_NO_STARTUP=1`.
- herdr: a separate server, session `t135-v4`, socket
  `/tmp/t135v4/config/herdr/sessions/t135-v4/herdr.sock`. The real home and
  the real herdr server got no message.
- Workspace `w1`: pane `w1:p1` is agent `asker-scratch`, pane `w1:p2` is
  agent `parent-scratch` (the parent of `asker-scratch`). Agent records are
  in `/tmp/t135v4/home/.hive/state/agents/`.
- The TUI ran as `hive --no-startup` in a private tmux server
  (`tmux -L t135v4`) at 120x40. Keys went in with `tmux send-keys`.
- Ask JSON: two questions. `Scope` is multi-select with 3 options. `Order`
  has 2 options.

Commands:

```sh
source /tmp/t135v4/env.sh
cd /tmp/t135v4/home && hive ask --agent asker-scratch --file /tmp/t135v4/ask1.json
tmux -L t135v4 send-keys -t tui KEY
tmux -L t135v4 capture-pane -p -t tui > v4/STEP.txt
herdr pane read w1:p1 --source recent --format text
```
