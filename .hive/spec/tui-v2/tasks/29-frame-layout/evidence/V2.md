`internal/lib/cellgrid` and compared them with the board grid. Main,
CompactAgents, and Compact: rows 0-2 and the footer. Help: the frame and the
help box (rows 6-34, columns 18-101) in full, and the token only in each other
cell that is not a space. TooSmall: the whole grid. The live rule of the
manager decision applies: in a space cell, the token and the bold flag are not
compared.
