## Repair after verify fail `t29-verifier-1`

The verifier found that `1` left the Compact Work details overlay. The cause:
`updateFrameKey` in `internal/tui/frame.go` sent the screen keys, `tab`, and
`[` `]` before the details route. Only the Agents popup had its own route.
The fix adds an overlay route before the global keys. Below 120 columns, the
details region of a list and details screen takes `esc`, `↑` `↓` `j` `k`
`pgup` `pgdn`, the action keys of decision 23 (`<` `>` on Logs only), and
`ctrl+c`. It drops each other key (decision 21). From 120 columns the details
region is a normal region, and each key stays global.

| `TestOverlayGivesActionKeysToTheScreen`: `d` in the Work overlay opens the dependency graph. | AC2 |
