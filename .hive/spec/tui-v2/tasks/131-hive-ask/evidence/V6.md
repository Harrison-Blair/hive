## Finding fixed during this run

The first start of the TUI had its cwd in the worktree, below `projects/`.
Chat refused input (rule 2), but the ask card still sent answers, which carry
`⬢ user:` authority. Fix: `closeAsk` in `internal/tui/ask.go` sends nothing
when the chat caller is blocked. Test `TestABlockedCallerCannotAnswer` failed
before the fix (`a blocked caller sent [{answer a1 [{[1]  }]}]`) and passes
after it.
