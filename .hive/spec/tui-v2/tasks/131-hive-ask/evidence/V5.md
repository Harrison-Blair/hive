# V5 Visual alignment

Proves AC4 to AC6. Run again on 2026-10-23 by the worker after the verifier
fail, with the updated brief: the cell-for-cell capture uses
`hive --demo FILE --size WxH` on the fixture of each board, in a real herdr
pane of a scratch session at the board size. Result: **pass**.

## Method

- Build: `go build -o .hive/tmp/hive .` at the repair commit.
- Scratch herdr session `t131-w2` of my own, in a private tmux server
  `t131w2`, with each `HERDR_*` variable removed. Pane `w1:p1`. `stty size`
  in the pane gave exactly `40 120` (tmux 155×41) for the 120×40 boards.
- Each board: `v5-demo/cap.sh BOARD W H v5-demo`. It runs
  `TERM=vt100 COLORTERM=truecolor .hive/tmp/hive --demo .hive/spec/tui-v2/design/BOARD.fixture.json --size WxH`,
  reads the pane (`--source visible --format ansi`) every 500 ms until two
  reads are equal, converts the read with `cellgrid.Convert`, and compares it
  with the committed grid with `cellgrid.Compare` and no mask. The compare
  tool was a scratch build in `.hive/tmp/gridcmp/`, removed after the run. Its
  source is `v5-demo/gridcmp.go.txt`. Each demo quit
  with two `ctrl+c` presses.
- The compare tool finds a mismatch: `v5-demo/mismatch-check.txt` (1526 and
  1142 cells differ against a wrong grid).

## 80×24: the pane of exactly 80 columns

In a pane of exactly 80×24 (`stty size` `24 80`), `CompactChatAsk` gave 20
differing cells (`CompactChatAsk-80x24-pane80x24.*`). Each one is a blank
cell at the right edge (row 0 col 79, row 23 cols 61 to 79): the board has a
bold or dim space, the read has no cell. When a row reaches the last column
of the pane, `pane read --format ansi` stops the row at the last non-blank
character, and `Convert` fills the missing cells with a plain `fg` space. The
TUI output is the same in each pane: the same build and demo gave 0
differences in a larger pane (V4 and the verifier V4). So I ran the board
again in a scratch pane of 81×25 (tmux 116×26), as decision 43 permits (a
pane equal to or larger than the board, cropped at the top-left W×H cells).
That run gave 0 differences.
