# V5 Visual alignment

Proves AC4 to AC6. Run on 2026-10-23 by the worker. Result: **pass**.

## Method

Two runs of the task build (`go build -o .hive/tmp/hive .`):

1. **Board captures.** The TUI in demo mode from each board fixture, in the
   worker's own herdr pane `wWD:p2`, at the board size:
   `TERM=vt100 COLORTERM=truecolor .hive/tmp/hive --demo .hive/spec/tui-v2/design/BOARD.fixture.json --size WxH`.
   Demo mode is the real TUI program (the same `Model`, `View`, and key
   handling) with fixture loaders; task 126 used the same method. Each capture
   was compared with its approved grid cell by cell (`cellgrid.Compare`, no
   mask), as in V4. Captures: `v5/BOARD-WxH.ansi` and `.png`. Diffs:
   `v5/BOARD-WxH.diff.txt` (each empty, 0 cells differ).
2. **Real home.** The TUI on the V6 scratch home (`HIVE_HOME=.hive/tmp/v6/home
   HIVE_NO_STARTUP=1`, cwd outside `projects/`) with a two-question ask open
   from `hive ask`. A herdr pane in the scratch session gave 119 columns (herdr
   keeps one column), and a pane of the worker tab follows the client size
   (206×57). So this run used a private detached tmux server
   (`tmux -L t131v6 new-session -d -x 120 -y 40`) for an exact 120×40 terminal.
   Capture: `v5/real-ask-120x40.ansi` and `.png`. Its content is live data, so
   it is not compared with a grid; the points below are checked on it.

Columns are 0-based. Rows are 1-based.
