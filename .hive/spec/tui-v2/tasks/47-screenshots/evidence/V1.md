## The command

Run it from the worktree root. `S` and `OUT` have defaults; the V1 rerun and the symbol page set them.

```sh
S=${S:-/home/penguin/source/hive/.hive/tmp/reports/tui-v2-signoff}; OUT=${OUT:-.hive/spec/tui-v2/screenshots}; FONT=.hive/tmp/font/fonts/ttf/JetBrainsMono-Regular.ttf; mkdir -p "$OUT"; for a in "$S"/*.ansi; do n=$(basename "$a" .ansi); read -r _ _ c r < "$S/$n.grid"; freeze -c base --font.file "$FONT" --font.size 28 --font.ligatures=false --line-height 1.32 --theme charm --background '#171717' --padding 40 --window=false --width "$(echo "$c*16.8+80" | bc)" --height "$(echo "$r*36.96+88.4" | bc)" --output "$OUT/$n.png" < "$a" || exit 1; done
```

The settings:

- Font JetBrains Mono from the TTF file, size 28 px, no ligatures. `freeze` v0.2.2 ignores the bold attribute (its bold case in `ansi.go` is commented out), so bold cells show at regular weight.
- Dark theme: `charm` with background `#171717`. Base config `base`, so a user config cannot change the result. No window controls, no border, no shadow.
- Padding 40 px.
- Window size from the board size. JetBrains Mono has an advance of 600/1000 em and ascent + descent of 1020 + 300 = 1320/1000 em. At 28 px a cell is 16.8 × 36.96 px, and line height 1.32 makes the box lines join with no gap. Width = cols × 16.8 + 2 × 40. Height = rows × 36.96 + 2 × 40 + 8.4 (the 0.3 em descent of the last row, which the freeze clip path would cut).
- No `--wrap`. `freeze` wraps only with `--wrap`. A fixed width and height gives a scale of 1 and removes each text line below the last board row.
- Stdin input. With a file argument, `freeze` v0.2.2 did not finish in 120 s; with stdin it detects ANSI and runs.
