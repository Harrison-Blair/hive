## Method

The task build `.hive/tmp/hive` ran in the worker's own herdr tab
`t125-demo` (pane `wVT:p2`), with
`clear; TERM=vt100 COLORTERM=truecolor .hive/tmp/hive --demo FIXTURE --size WxH`.
After each key, the worker read the pane until two reads 500 ms apart were
equal (`--source visible --format ansi`), and saved the plain text
(`--format text`). A scratch script changed the SGR codes of the top-left
W×H cells to an HTML `<pre>`. Firefox captured it
(`firefox --headless --no-remote --profile SCRATCH --window-size=… --screenshot`).
The scratch tools, the HTML files, and the profile folders were removed after
the run. Each demo quit with two `ctrl+c` presses.

Files in `v5/`: `NAME.ansi` (pane read), `NAME.txt` (plain text), `NAME.png`
(capture), and for each capture at the board size `NAME.diff.txt`.
