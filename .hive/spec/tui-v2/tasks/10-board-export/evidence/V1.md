## Red run

The base is `dev` at `0b3296b2`, in a scratch worktree. The red run copies the
three new test files into `internal/boardexport/` and adds one stub file. The
stub gives each new symbol an empty body and holds the spec size table as
data. The stub `ToGrid` returns a zeroed grid of the requested size, so that
each test reaches its assertion and no index panic stops the run. The base has
no grid files, so `TestGoldenGridFiles` fails on the missing files.

