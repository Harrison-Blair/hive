## Finding: herdr gives done, not idle

The tab of `g1` is not focused, so herdr gives `done` for the ready agent. `reference/herdr/data-model.md` states that `done` is "the same idle status as `idle`" in a tab that nobody saw. The first build sent the prompt only for `idle`. Commit `f1d6673f` ("send a kept first prompt when herdr reports done") also accepts `done`, as the nudge rule does. The test `TestKeptFirstPromptSentWhenDone` covers it (see V-red). The binary was built again before the supervisor started.
