had `hive task verify --task ID --agent NAME`. `hive task verify` accepts only a
verifier caller (`internal/task/transition.go`). A manager can use this line
only when NAME names the verifier, which is another agent. AC1 now refuses
this in a herdr pane. The line is removed. The verifier skill keeps its own
