links of the other hive skills.

## Without the link

No test lists the skill links. `skills_test.go` and `ste_test.go` list only
`.agents/skills/*/SKILL.md` paths. `gitignore_test.go` lists no skill path.
So the brief permits no edit to these tests, and a removed link does not make
a test fail:

```text
$ rm .claude/skills/hive-agent
$ git status --short
 D .claude/skills/hive-agent
$ go test .
ok  	github.com/Harrison-Blair/hive	1.686s

$ readlink .claude/skills/hive-agent
../../.agents/skills/hive-agent
```
