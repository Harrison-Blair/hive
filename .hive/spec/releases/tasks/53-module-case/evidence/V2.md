The worker made a bare clone of the worktree in `.hive/tmp/repo.git`, with the
local tags `v0.9.7` at the task commit `63576b2d` and `v0.9.6` at the base
`19988d4c`. A scratch Git config redirects the module URL to this clone. Go
then makes the module zip from Git, as for a real tag. The worker pushed no tag
to `origin`.

The first try used `GOSUMDB=off`. Go stopped before the zip, because it must
verify the `go1.27.2` toolchain. The run below keeps the checksum database and
sets `GOPRIVATE` for hive only.

```sh
cd .hive/tmp
git clone -q --bare /home/penguin/source/hive/projects/hive/worktrees/53-module-case repo.git

printf '[url "file://%s/repo.git"]\n\tinsteadOf = https://github.com/Harrison-Blair/hive\n' "$PWD" > gitconfig
export GIT_CONFIG_GLOBAL=$PWD/gitconfig GOMODCACHE=$PWD/modcache GOPRIVATE=github.com/Harrison-Blair/hive GOFLAGS=-modcacherw GOBIN=$PWD/bin
```
