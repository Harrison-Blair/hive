## Observations

- The clone, `go install` from the local checkout path, and `hive init` in the
  clone each exit 0. `hive init` writes the clone path to the scratch config.
- `sha256sum --check --ignore-missing checksums.txt` passes for a correct
  archive and ignores the absent arm64 archive. It exits 1 for a changed
  archive.
- `hive init` in a clone below another home does not use the clone. It uses
  the outermost marker (`internal/lib/home/home.go:46`). In a first run of
  this check, before this run, a nested clone below `.hive/tmp/` printed
  `Initialized hive home at /home/penguin/source/hive` into the scratch config.
  In the run above it exits 1 with a home conflict. Thus the init check runs in
  a clone outside the home. The README tells a user to clone into a new
  directory such as `~/hive`.
- `~/.config/hive/` is an empty directory before and after. The real home stays
  at `19988d4c`. The cleanup block is the last block of the run.
