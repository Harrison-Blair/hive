## Limits

- Go accepts only a `v0` or `v1` version for the module path
  `github.com/Harrison-Blair/hive`. A `v9.9.8` install fails with
  `invalid version: should be v0 or v1, not v9`. The manager approved
  `v0.9.8` for this item.
- Go rejects a module zip of `HEAD`: 8 tracked files have names that differ
  only in letter case. They are in three folders below `.hive/spec/tui-v2/`.
  The module copy omits these three folders. Task 53-module-case removes the
  clashes. Until then, a real `go install ...@vX.Y.Z` fails.

## Run

```sh
T=$PWD/.hive/tmp/v2
go build -o $T/bin/plain/hive .
go build -o $T/bin/ldflags/hive -ldflags "-X github.com/Harrison-Blair/hive/internal/lib/version.Version=v9.9.9" .
# module copy and a file GOPROXY with v0.9.8
V=v0.9.8; P=$T/proxy/github.com/!harrison-!blair/hive/@v
mkdir -p "$P" $T/src && git archive HEAD | tar -x -C $T/src
rm -rf $T/src/.hive/spec/tui-v2/tasks/34-screen-chat/evidence/screens \
  $T/src/.hive/spec/tui-v2/tasks/35-screen-work-goals/evidence/verifier3 \
  $T/src/.hive/spec/tui-v2/tasks/35-screen-work-goals/evidence/verifier4
mkdir -p $T/z/github.com/Harrison-Blair && ln -s $T/src "$T/z/github.com/Harrison-Blair/hive@$V"
(cd $T/z && zip -qr "$P/$V.zip" "github.com/Harrison-Blair/hive@$V")
cp go.mod "$P/$V.mod"; echo "{\"Version\":\"$V\",\"Time\":\"2026-10-22T00:00:00Z\"}" > "$P/$V.info"; echo $V > "$P/list"
cd / && GOFLAGS=-modcacherw GOBIN=$T/bin/install GONOSUMDB=github.com/Harrison-Blair/hive \
  GOMODCACHE=$T/modcache GOPROXY="file://$T/proxy,https://proxy.golang.org" \
  go install github.com/Harrison-Blair/hive@v0.9.8
```
