# V1 Time zones, red and green

Proves: AC1.

## Cause

The code is correct. The Chat frame shows each transcript time and the status
row clock in the zone of the TUI clock (`m.now().Location()`, `internal/tui/chat.go:452`).
The test clock `testClock.now` gives the instant in `time.Local`. The six tests
expect the text in US Eastern time (07:30, 08:00 for the instant
2026-10-20T11:30Z and 12:00Z). They pass only where the local zone is EDT.

## Fix

Test-only. `inEastern` in `internal/tui/ask_test.go` puts the clock of the model
in `time.FixedZone("EDT", -4h)` and rebuilds the transcript. Each of the six
tests calls it after it makes the model. The expected texts do not change.
No product code changed.
