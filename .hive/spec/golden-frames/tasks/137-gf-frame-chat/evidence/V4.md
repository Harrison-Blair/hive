## Pane

The herdr window of the default session gave a pane of only 104×49, so hive showed `terminal too small`. The worker started the scratch session `t137-check` with its client in a 170×50 pty. Its pane `w1:p1` had the name `t137-check-live`. The worker stopped and deleted the session after the check, and closed the scratch tab `t137-check-live` of the default session.

The worker built the task code as a scratch binary and ran it in the pane:

```sh
TERM=vt100 COLORTERM=truecolor HIVE_HOME=WORKTREE hive --demo .hive/spec/golden-frames/design/BOARD.fixture.json --size 120x40
```

`TERM=vt100` follows the `tui-v2` task 122 V4 note: it stops the ECH optimization of Bubble Tea, so that herdr reports blank cells with no token.

The driver (`captures/live_driver.py.txt`) reads the pane with `pane.read`, `source: visible`, `format: ansi` on the socket. It refuses a read with `truncated: true` or a scroll offset other than 0. It waits until two reads 500 ms apart are equal. A scratch test (`captures/live_compare_test.go.txt`) crops the top-left 120×40 cells, converts them with `cellgrid.Convert`, and compares them with the golden grid.
