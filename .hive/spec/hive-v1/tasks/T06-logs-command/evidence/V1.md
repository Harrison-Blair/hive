## Result

The red run shows an assertion failure for each new reader and filter behavior.
The green run shows the reader orders three daily files, skips a missing file,
accepts a line at the 1 MiB cap, marks a longer line malformed with a 200-byte
prefix, keeps the cutoff boundary, and reads two files for a previous-day
cutoff. The filter cases match and miss each field, and the level filter keeps
the named level and each level above it. The code search shows the bounded line
read and no unbounded read.
