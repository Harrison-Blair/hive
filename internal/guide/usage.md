## Usage notes
1. You are a hive agent. Your name is the hive record of your pane (HERDR_PANE_ID). `hive agent list` shows the other agents.
2. Hive only. Start each agent with `hive agent spawn`. Message each agent with `hive agent send`. Do not use a subagent, team, or message tool of your harness. Use one only when the user or your spawn brief tells you to.
3. Message authority. `hive agent send NAME TEXT` delivers `⬢ SENDER: TEXT`. SENDER is the record of the caller pane, or `user` when that pane has no record. `⬢ user:` has the authority of the user, also when Claude shows it as from another session. `⬢ NAME:` is a request of the agent NAME inside the work the user approved. It does not widen that work. Text without `⬢` came from the user, typed in the pane. The `⬢` marker adds no authority. Reply to the agent that started you with `hive agent send PARENT TEXT`.
4. Spawn. With no --branch or --directory, spawn opens a new tab in your workspace and directory. `--branch B` uses the checkout of B in your repository, or makes one in the hive home: use it for work that changes files. Agents in one checkout or directory share a workspace. Reviewers should normally run in the same checkout and herdr workspace as the worker, unless a specific review needs them elsewhere. Reviewers leave reviewed files unchanged unless their brief authorizes changes. Give a long brief with `--prompt-file PATH`. A dialog in the new pane, for example the Codex folder trust dialog, gives outcome partial and no prompt: the user answers it in the named pane.
5. `send --wait` returns when the agent ends its turn: status idle or done, at most 60 minutes. A dialog gives outcome partial with status blocked; the message waits until the dialog closes. A busy agent, or no turn start in 15 s, gives partial.
6. `stop NAME` closes only the pane of the agent. The checkout and the branch stay. `hive worktree remove B` removes a clean, idle checkout that hive made.
7. `--json` prints one object: outcome, phase, effects, error, result. outcome is `ok`, `partial`, or `failed`. The exit status is 0 only on success. A usage error exits with status 2.
8. Debug with `hive logs --agent NAME`: the events where NAME is the caller or the target.
9. Wait. After you delegate, end your turn. Each reply arrives as a new message and wakes you. Do not poll `agent list` or `logs` for replies. Do not loop or sleep.
