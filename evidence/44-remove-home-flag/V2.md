# V2 — CLI behavior

Built the task binary in `.hive/tmp/44-remove-home-flag/hive`. The check used a new temporary `XDG_CONFIG_HOME` and did not set `HIVE_HOME`, except for the fixture command.

1. `hive --home /tmp task list --project hive` printed `hive: unknown flag: --home` and exited 2.
2. `hive task list --project hive` from the worktree resolved the outer home from its marker, listed the home tasks (including task 44), and exited 0.
3. `HIVE_HOME=<temporary marked home> hive task list --project x` from the worktree printed `no tasks` and exited 0. It used the fixture home and returned no `home conflict` error.

The check did not read or write the user's config file. The task-list command wrote its normal log event in the home.
