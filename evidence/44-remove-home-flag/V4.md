# V4 — Race tests with an external config

Created a temporary `XDG_CONFIG_HOME` with `hive/config.toml` set to a different temporary marked home. Ran:

```text
env -u HIVE_HOME XDG_CONFIG_HOME=<temporary config directory> go test -race ./... -count=1
```

All packages passed. The temporary config directory and marked home were removed after the run. The user's config was not read or written.
