## Changes

- **Hive v1 replaces Fledge:** a Go CLI and TUI that coordinates coding-agent work through herdr, with durable project and task state, isolated worktrees, and verified delivery. The Fledge implementation, its documentation, and the legacy CI and release workflows are removed.
- **Projects and tasks:** home-scoped project registry, durable role and task records, inboxes, dependency checks, task verification, worktree management, and grant-based delivery.
- **Agent lifecycle:** herdr-backed spawn, send, and stop commands, harness profiles, event-driven supervision and recovery, structured JSON logs, doctor checks, and scoped memory and handoff commands.
- **Startup tracking:** spawned agents are `starting` until ready, with startup-aware agent commands, supervision, doctor checks, and TUI status.
- **Task repair and verification:** `hive task reopen` moves a verified task back to assigned, preserves verification history, and requires a new passing verification before landing. `hive task edit --brief` updates the brief of a created or assigned task. `hive task verify` refuses a dirty worktree or a local branch with commits that are not pushed before it records a verdict.
- **Worker respawn:** Hive assigns the new worker, reopens the existing worktree workspace when its pane is gone, and selects a free name when `--name` is absent.
- **Inbox ownership:** agents can read their own role inbox. The coordinator can inspect a manager inbox without marking records read; other callers cannot read another role's inbox.
- **Supervisor notifications:** unread `quiet` records do not cause nudges. Each nudge starts with `⬢` and tells the agent to run `hive inbox`, without a `--home` flag or home path.
- **Agent startup:** the first prompt waits for a working or blocked state and retries one stalled prompt. Hive reports an agent as live only after it confirms the prompt. Each message that Hive types into an agent pane starts with `⬢`. Claude Code and Codex agents start with their harness bypass flags.
- **CI:** GitHub Actions runs the gate on pushes and pull requests to `main` and `dev`, on `ubuntu-latest`. The CI flake fixes address a TUI race, supervisor watcher shutdown, and intermittent inbox and store lock timeouts without disabling tests.
- **Documentation and dogfooding:** the live log TUI, Hive v1 design spec, role playbooks, and task evidence remain. A structured friction folder replaces the single friction log; its idle-session nudge entry is resolved after the quiet-record change.
